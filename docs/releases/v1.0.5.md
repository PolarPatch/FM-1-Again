# FM-1 Again 1.0.5

- **The screensaver no longer flashes up while you play:** a key or pad press could start the screensaver's film for a
  moment, so bits of it showed through the page on the screen and in the screen mirror (FM-1 Live, the web mirror).
- **The screen mirror mends at once after the screensaver:** waking it with a key, the page comes back whole in the
  mirror within a moment instead of up to two seconds with bands of the film left in it.
