# FM-1 Again 1.0.6

- **Ableton Link over Wi-Fi:** FM-1 Again plays in time with Link apps (Ableton Note, Live and many others) on a
  phone, a tablet or a computer. The new LINK page (GLO, a fifth press) turns on the Wi-Fi and Link:
  - **WI-FI AP:** the FM-1 makes its own network; its name and password show on the page, so you can join it from your phone anywhere.
  - **WI-FI AUTO:** the FM-1 joins a network you gave it over USB once (`fm1_remote.py wifi join`).
  - **With Link on:** the tempo goes both ways. Starting and stopping in an app starts and stops the groove (at the
    next bar line), and FM-1 Again stays on the session's beat.
- Link shares the tempo, the beat and start / stop: each device plays its own sound.
